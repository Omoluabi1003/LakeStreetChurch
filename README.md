# Lake Street Church of Christ Website

Public-facing church website with Tailwind CSS-based styling.

## Project at a glance

- **Purpose:** Public-facing church website with Tailwind CSS-based styling.
- **Repository:** https://github.com/Omoluabi1003/LakeStreetChurch
- **Status:** Repository documentation foundation. Review implementation before describing features as production-ready.
- **Audience:** Contributors, technical reviewers and prospective users.

## Getting started

Run `npm install` and `npm run build:css` to generate `dist/output.css`; open the project's HTML pages using a static server.

## Scope and limitations

Review published content and church details with the organization before deploying changes.
